# Mission Reflection

Object storage is better suited for storing millions of photos because it is designed for large amounts of unstructured data. Photos can be stored as individual objects and accessed when needed. This makes object storage useful for applications that need to store many images.

Docker made it easier to deploy the MinIO storage server because the server could be started using a single Docker command. Instead of manually installing and configuring all the required software, Docker provided the MinIO environment in a container. The ports and administrator credentials could also be configured using the Docker command.

A bucket is a storage container used to organize and store objects in object storage. In this activity, the bucket named `client-photos` was used to store the sample uploaded file.

Large enterprise companies can help prevent data loss by keeping copies of their data on multiple physical servers or locations. They can also use backups and redundancy so that data can remain available even if a physical server crashes.

My confidence in navigating the Linux command line is growing because I am becoming more familiar with commands and how they are used to manage cloud services. Using Docker commands in the KillerCoda Playground also helped me understand how command-line tools can be used to deploy applications.
